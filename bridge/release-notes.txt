Herdcats Bridge __BRIDGE_VERSION__ — agent compatibility fixes

Herdcats Bridge (`herdcats-bridge`) is the optional companion on your SSH computer that powers Claude, Codex, Agy, Pi and Cursor Agent Timelines in Herdcats.

Changes since 0.5.0:
- Pi, Agy and Cursor no longer require one exact CLI version. Pi validates its public extension APIs and Herdcats extension protocol 1; Agy and Cursor retain catalog, session identity, composer, screen and confirmation guards. Pi reports its actual CLI version, and Cursor rescans its model catalog when the running build changes.
- Codex activity includes tool definitions in the timeline.
- Security hardening protects bridge hook/configuration handling and validates persisted Cursor catalog cache data.

Install or update on the SSH computer running Herdr and your agents:

curl -fsSL https://github.com/zhiyao/herdcats/releases/download/herdcats-bridge-v__BRIDGE_VERSION__/install.sh | sh -s -- --version __BRIDGE_VERSION__ --replace

Requires macOS 13+ or Linux with glibc 2.35+ (Ubuntu 22.04+), curl and SHA-256 tooling. Apple Silicon, Intel Mac, Linux arm64 and x86_64 binaries are included. Herdr protocol 22 and an exact native session reference are required. No root access, Rust, Python or persistent service is needed. Phone answers for Claude, and for Codex approvals, use an optional recording hook installed only after confirmation.

The existing iOS one-click installer remains pinned to 0.5.0 until this release is published, its assets are verified, and a separate app pin update ships. Existing compatible iOS builds can use a manually updated bridge. This release does not add launch-time update discovery to the currently published iOS app.

Pi users must update the extension as well as the bridge:
1. Download herdcats-pi-extension.tar.gz and SHA256SUMS from this release and verify the archive with sha256sum or shasum -a 256.
2. Extract it and replace the installed Herdcats extension files, keeping herdcats/index.ts and herdcats/runtime.mjs together. For a new session, enable it with pi -e /absolute/path/to/herdcats/index.ts.
3. In an existing Pi TUI, run /reload after replacing the files. Reloading the old extension files does not apply this update.
4. Return to Herdcats and tap Check again if needed.

The binary installer does not install, update or enable the Pi extension, and the extension does not change Pi permission policies. Custom/editor dialogs, slash commands and authentication remain in Terminal when their contracts cannot be verified. Newer CLI versions are covered by regression fixtures; live validation of every newer release is not implied.

Checksums detect damaged downloads and come from the same HTTPS release channel. Binaries are not Developer ID signed/notarized. Saved-machine routing remains unavailable.
