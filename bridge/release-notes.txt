SOURCE CHANGE — not a published Agy or Cursor release. The app installer remains pinned to 0.3.0 until an actual artifact and checksum are verified.

Herdcats Bridge (`herdcats-bridge`) is the optional companion on your computer that powers native Claude, Codex, Agy and Cursor Timelines in Herdcats.

Changes in this source version:
- Cursor conversations: the Cursor CLI history follows the exact chat Herdr reports (never the working directory), prompts are sent only when the screen shows an idle empty composer, shell approvals offer Run once and Skip, AskQuestion forms are answered one question at a time, and model and effort changes use the live /model picker on the verified Cursor build 2026.10.22-27dcf5f. Cursor saves a model or effort change to its own settings, so it also becomes the default for new Cursor sessions. Messages that start with / are not sent from the phone. Everything else stays in Terminal.
- GPT-OSS 120B model observation and switching accept its exact catalog-label idle footer (GPT-OSS 120B (Medium)), alongside the existing model · effort footer. Empty-composer checks share catalog verification and retain draft, border, source and stale-session guards.
- Agy model families and discovered per-family efforts are normalized by the bridge across status, snapshots, events and set results. Native IDs remain internal for guarded submission and confirmation; legacy exact native target IDs remain accepted. Family switches preserve effort when available, otherwise prefer Medium, Low, then High. Rebuild the app and source bridge; the installer pin is unchanged.
- Agy user bubbles unwrap only the recognized outer USER_REQUEST/ADDITIONAL_METADATA envelope (optional USER_SETTINGS_CHANGE), including single/double LF or CRLF separators. Literal user text and raw inspectable records remain intact.
- Agy questions and command approvals now use verified native records plus live dialogs when Herdr mislabels the pane idle/done/working. Effective blocked status disables composition; uncertain pending state and model/composer guards fail closed. Claude/Codex status gates and caching are unchanged.
- Agy history follows the exact Herdr native conversation with bounded, pinned-root transcript reads. Verified 1.4.7 command approvals, single/multiple questions, write-in and multi-select answers use guarded terminal controls; unverified cards stay in Terminal. Model controls use the installed CLI catalog and idle empty composer checks; /model may persist across sessions.
- Change the model and reasoning effort of a Claude or Codex session from your phone. The bridge reads the current model from the session, then types `/model` or `/effort` only when the agent is idle and its input box is empty, and checks every screen before the next key. Claude's "Switch model?" question is answered only when it names exactly what you picked.
- Codex changes apply to that session only and never write config.toml. Claude saves the new model and effort as your default for new sessions, as `/model` and `/effort` do at your desk.
- Claude timelines no longer show local command records such as `/effort` and its output.

Install on the computer Herdcats connects to with SSH, the one that runs Herdr and your agents:

curl -fsSL https://github.com/zhiyao/herdcats/releases/download/herdcats-bridge-v__BRIDGE_VERSION__/install.sh | sh -s -- --version __BRIDGE_VERSION__

Requires macOS 13+ or Linux with glibc 2.35+ (Ubuntu 22.04+), curl and SHA-256 tooling. Apple Silicon, Intel Mac, Linux arm64 and x86_64 binaries are included. Herdr protocol 22 and an exact Claude or Codex session reference are required. No root access, Rust, Python or persistent service required. Phone answers for Claude, and for Codex approvals, use an optional recording hook that Herdcats installs only after you confirm. Existing installation upgrades require --replace.

Checksums detect damaged downloads; they are provided through the same HTTPS release channel. These binaries are not Developer ID signed/notarized. Saved-machine routing remains unavailable.

After installing, return to Herdcats and tap Check again.
