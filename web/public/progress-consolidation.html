Design System & HIG Architecture

Audit of 16 Progress Indicators & 3 Consolidation Paths

Herdcats orchestrates remote coding agents over SSH. Currently, 16 distinct progress views, hand-rolled circular stroke animations, rotating SF symbols, and pixel cat canvas runners exist across the app with divergent sizes and tints. This interactive suite demonstrates the current state and 3 concrete directions forward.

3 Strategic Approaches to Consolidate Spinners & Progress

Choose the architecture that best balances Apple HIG fidelity, code minimalism, and Herdr's hacker-chic terminal personality.

Option 01 · Minimalist

Semantic Native Scale

Strict adherence to standard Apple SwiftUI .controlSize. Replaces all one-off custom geometry with native spinners.

  • ✓
    Standardize 3 Sizes: .mini for chips/tags, .small for all buttons, .regular for view loading.
  • ✓
    Kill Custom Stroke Arc: Replaces the hand-rolled Circle().trim in Live keyboard with ProgressView().controlSize(.mini).tint(Theme.accent).
  • ✓
    Fix Reduce Motion: All spinners instantly respect iOS system accessibility with zero custom boiler-plate.
  • ✓
    Remove Icon Duplication: Eliminates static arrow.clockwise sitting beside active spinners in status bars.
  • ✓
    Smallest Footprint: Zero new UI dependencies or custom view models needed.
Native SwiftUI First Recommended for Simplicity
Option 02 · Design System

Unified Token Primitives

Introduce a standardized HerdrSpinner and a .herdrButtonLoading() modifier in Features/DesignSystem.swift.

  • ★
    Zero Layout Jumps: Button modifier locks explicit button bounding box so text-to-spinner swaps never shift surrounding elements.
  • ★
    Semantic Sizing Tokens: HerdrSpinner(size: .compact, tint: .white) replaces repetitive Group { if isBusy { ProgressView() } else { ... } }.
  • ★
    Unified Sheet Loader: Standard HerdrLoadingState(message: "Loading worktrees…") replaces mixed ProgressView("...") and manual VStacks.
  • ★
    Centralized Haptics & Accessibility: Enforces accessibility labels and motion reduction in a single source of truth.
DesignSystem.swift Primitives Highest Engineering Quality
Option 03 · Brand-Led

Context-Adaptive Tiering

Categorize spinners strictly by semantic domain to provide instant peripheral situational awareness.

  • ◆
    1. Remote SSH Handshake: Pixel Tabby Cat (LazyCatLoadingView) exclusively for host connections.
  • ◆
    2. Agent Autonomous Thinking: Amber rotating WorkingStatusIcon exclusively for Herdr agent process state.
  • ◆
    3. Terminal Stream Activity: Cyan mini pulse indicator for Live queue/raw PTY keystrokes.
  • ◆
    4. Local App Interactions: Subdued monochrome Apple ProgressView for standard user taps (Send, Mark Read, Export).
  • ◆
    5. Capacity Tracking: Determinate QuotaRing for percent burn rates.
Domain Specific Archetypes Highest Visual Personality

Recommended Swift Consolidation Code

Drop-in extensions for ios/Herdcats/Features/DesignSystem.swift and Components.swift.

// MARK: - DesignSystem.swift: Canonical Progress Sizes & Modifiers enum HerdrSpinnerSize { /// 12pt — micro chips, pending placeholder tags, connection status bar case mini /// 16pt — standard buttons (Connect, Send, Mark As Read, Refresh) case button /// 22pt — full-view, modal sheet, or empty state loading case regular var controlSize: ControlSize { switch self { case .mini: return .mini case .button: return .small case .regular: return .regular } } } // MARK: - Unified HerdrSpinner Component struct HerdrSpinner: View { var size: HerdrSpinnerSize = .button var tint: Color? = nil var body: some View { ProgressView() .controlSize(size.controlSize) .tint(tint) } } // MARK: - Clean Button Loading Modifier (Prevents Layout Jumps) extension View { func inFlightProgress(isLoading: Bool, tint: Color = .white) -> some View { self.overlay { if isLoading { HerdrSpinner(size: .button, tint: tint) } } .opacity(isLoading ? 0 : 1) .disabled(isLoading) } }
